# COSMII rides

Runtime: home character area -> のりもの. Skate unlock costs 300 coins, bicycle 600 coins, once per device/save and shared across all five characters. Run is free. Unlocks and selected ride persist in cosmii_rides_v1. An interrupted purchase journal restores the previous coin balance and ownership. The same jump physics, character abilities and hitbox apply to every ride. Ground animation is distance-driven; airborne pose uses frame 2. Artwork scale is 1.65 for skate and 1.9 for bike, anchored at the wheels. Prices live in cosmii-rides.js.

Built-in image_gen, 2026-11-08. Ten right-facing sheets, 4 frames each (2 x 2). Shared scale and feet alignment, 256px cells, fit 0.98, chroma threshold 25 / edge threshold 80, largest component, reject edge touch. Runtime uses final transparent 512px sheets only. Source images remain in the Codex generated_images archive.
